# Ringkasan Discovering Computers

## BAB 2 — Connecting and Communicating Online

### 1. Internet

Internet adalah jaringan global yang menghubungkan jutaan komputer, perangkat, organisasi, lembaga pendidikan, dan individu di seluruh dunia.

Internet bermula dari **ARPANET pada tahun 1969** dengan tujuan:

* Memungkinkan para ilmuwan berbagi informasi dan bekerja sama.
* Menjaga jaringan agar tetap berfungsi meskipun sebagian jaringan mengalami kerusakan.

### 2. Koneksi Internet

Koneksi internet terbagi menjadi dua jenis:

**Wired (Kabel):**

* Cable Internet
* DSL
* FTTP (Fiber to the Premises)

**Wireless (Nirkabel):**

* Wi-Fi
* Mobile Broadband
* Fixed Wireless
* Satellite Internet

Istilah penting:

* **ISP:** Penyedia layanan akses internet.
* **Bandwidth:** Jumlah data yang dapat ditransfer melalui jaringan dalam waktu tertentu.
* **Hotspot:** Jaringan nirkabel yang menyediakan akses internet.

### 3. IP Address, Domain Name, dan DNS

* **IP Address:** Nomor unik untuk mengidentifikasi perangkat dalam jaringan.
* **Domain Name:** Nama berbentuk teks yang mewakili alamat IP.
* **DNS (Domain Name System):** Sistem yang menerjemahkan nama domain menjadi alamat IP.

### 4. World Wide Web (WWW)

World Wide Web adalah kumpulan dokumen elektronik atau halaman web yang dapat diakses melalui internet.

Istilah penting:

* **Website:** Kumpulan halaman web yang saling berhubungan.
* **Web Server:** Komputer yang menyediakan halaman web kepada pengguna.
* **Browser:** Aplikasi untuk membuka dan melihat halaman web.
* **URL:** Alamat unik suatu halaman web.
* **Web 2.0:** Website yang memungkinkan pengguna berbagi informasi, mengubah konten, dan menggunakan aplikasi melalui browser.

### 5. Jenis-Jenis Website

Contoh jenis website:

* Search engine
* Media sosial
* Website pendidikan
* Website berita
* Website bisnis dan pemerintahan
* Blog
* Website hiburan
* E-commerce
* Website perbankan
* Website kesehatan dan kebugaran

### 6. Media Digital

Media digital pada web meliputi:

* **Graphic:** Representasi visual dari informasi.
* **Infographic:** Penyajian data atau informasi secara visual agar mudah dipahami.
* **Animation:** Tampilan gerakan yang dibuat dari rangkaian gambar.
* **Audio:** Suara seperti musik dan percakapan.
* **Video:** Kumpulan gambar yang ditampilkan seolah bergerak.
* **Virtual Reality (VR):** Teknologi yang mensimulasikan lingkungan tiga dimensi.

### 7. Layanan Internet

* **Email:** Mengirim dan menerima pesan serta file melalui jaringan.
* **Instant Messaging:** Bertukar pesan atau file secara langsung.
* **Chat Room:** Tempat pengguna berkomunikasi secara daring.
* **Online Discussion:** Forum untuk berdiskusi mengenai suatu topik.
* **VoIP:** Teknologi untuk melakukan komunikasi suara melalui internet.
* **FTP:** Protokol untuk mengunggah dan mengunduh file melalui internet.

### 8. Netiquette

Netiquette adalah aturan atau etika dalam berperilaku dan berkomunikasi secara baik di internet.

## BAB 3 — Computers and Mobile Devices

### 1. Jenis Komputer dan Perangkat

Jenis komputer dan perangkat digital meliputi:

* Laptop
* Tablet
* Desktop
* Server
* Smartphone
* Kamera digital
* E-book reader
* Wearable device
* Perangkat game
* Embedded computer

### 2. Komputer Pribadi

* **Personal Computer (PC):** Komputer yang dapat melakukan proses input, pemrosesan, output, dan penyimpanan secara mandiri.
* **Laptop:** Komputer portabel dengan layar dan keyboard.
* **Tablet:** Komputer ringan dengan layar sentuh.
* **Desktop:** Komputer yang dirancang untuk digunakan di tempat tetap.

### 3. Server

Server adalah komputer yang menyediakan satu atau lebih layanan kepada komputer atau perangkat lain dalam jaringan.

Jenis server antara lain:

* Rack server
* Blade server
* Tower server
* Mainframe

Istilah terkait:

* **Virtualization:** Penggunaan perangkat lunak untuk membagi sumber daya komputasi menjadi beberapa lingkungan virtual.
* **Server Farm:** Kumpulan beberapa server yang berada dalam satu lokasi.

### 4. Terminal

Terminal adalah perangkat yang digunakan untuk mengirim atau menerima data dari server.

Contoh terminal:

* **POS (Point of Sale):** Digunakan untuk mencatat transaksi dan memperbarui persediaan.
* **ATM:** Mesin layanan perbankan mandiri.
* **Self-Service Kiosk:** Terminal mandiri yang biasanya menggunakan layar sentuh.
* **Thin Client:** Terminal dengan kemampuan dan komponen yang terbatas.

### 5. Cloud Computing

Cloud computing adalah lingkungan yang menyediakan sumber daya dan layanan komputer melalui internet.

Contohnya adalah penyimpanan data dan penggunaan layanan aplikasi secara online.

### 6. Perangkat Mobile

* **Smartphone:** Ponsel yang dapat terhubung ke internet dan menjalankan berbagai aplikasi.
* **Kamera Digital:** Perangkat untuk mengambil dan menyimpan foto secara digital.
* **Portable Media Player:** Perangkat untuk menyimpan, memutar, atau melihat media digital.
* **E-book Reader:** Perangkat yang digunakan untuk membaca buku elektronik.
* **Wearable Device:** Perangkat komputer kecil yang dikenakan pada tubuh.

### 7. Game Devices

Perangkat game digunakan untuk bermain game, baik secara individu maupun bersama pemain lain.

Contohnya:

* Game console
* Handheld game device
* Game controller seperti gamepad dan joystick

### 8. Embedded Computer

Embedded computer adalah komputer khusus yang menjadi bagian dari produk atau perangkat yang lebih besar.

Contoh penggunaannya:

* Peralatan elektronik
* Sistem otomasi rumah
* Kendaraan
* Robotika
* Mesin dan peralatan kantor

### 9. Port, Connector, dan Koneksi

* **Port:** Tempat perangkat tambahan terhubung atau berkomunikasi dengan komputer.
* **Connector:** Penghubung kabel dengan port.
* **USB:** Port yang dapat menghubungkan berbagai perangkat tambahan.
* **Bluetooth:** Teknologi komunikasi nirkabel jarak dekat.
* **Wi-Fi:** Teknologi jaringan nirkabel.
* **NFC:** Teknologi komunikasi nirkabel jarak sangat dekat.

### 10. Perlindungan Perangkat Keras

Cara melindungi perangkat keras:

* Menggunakan kontrol akses fisik.
* Memasang alarm keamanan.
* Menggunakan perangkat pelacak.
* Melindungi perangkat dari gangguan listrik.
* Menggunakan surge protector.
* Menggunakan UPS sebagai sumber daya cadangan.

Gangguan listrik yang dapat merusak perangkat:

* Undervoltage
* Overvoltage
* Power surge

### 11. Kesehatan dan Penggunaan Teknologi

Penggunaan teknologi yang tidak tepat dapat menyebabkan:

* **RSI (Repetitive Strain Injury):** Gangguan pada otot, saraf, tendon, ligamen, atau sendi akibat aktivitas berulang.
* **CVS (Computer Vision Syndrome):** Gangguan yang berkaitan dengan penggunaan layar dan penglihatan.
* **Technology Addiction:** Penggunaan teknologi secara berlebihan hingga mengganggu kehidupan sosial.

**Ergonomi** adalah ilmu yang menerapkan kenyamanan, efisiensi, dan keselamatan dalam merancang tempat kerja.

---

## Kesimpulan

Internet memungkinkan manusia berkomunikasi, berbagi informasi, dan mengakses berbagai layanan secara global. Komputer dan perangkat mobile membantu manusia melakukan pekerjaan, belajar, berkomunikasi, dan menjalankan berbagai aktivitas digital.

Pemahaman mengenai jaringan internet, jenis perangkat, cloud computing, koneksi, keamanan perangkat keras, dan ergonomi sangat penting agar teknologi dapat digunakan secara efektif, aman, dan bertanggung jawab.
